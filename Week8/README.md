# AI_Labs

## Bayesian Networks and Autoregressive Language Models

Files:

- `Bayesian_Networks_Autoregressive_Language_Models.ipynb` — executable first-order and second-order language-model implementation, CPTs, generation, and tests.
- `Bayesian_Networks_Autoregressive_Language_Models_Report.docx` — written answers to Questions 1–14, selected CPTs, model comparison, and LLM-use reflection.

### Run locally

1. Open the `.ipynb` file in Jupyter Notebook, JupyterLab, or VS Code.
2. Select a Python 3 kernel.
3. Run all cells from top to bottom.

No machine-learning library or pretrained model is required. The notebook uses only Python standard-library modules.
